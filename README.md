## 💝 À propos de ce site

Ce site est un **cadeau numérique du cœur** — une lettre d'amour construite page par page
pour célébrer trois dates précieuses :

| 📅 Date | 🎉 Célébration |
|:-------:|:--------------|
| **8 Mars** | 🌍 Journée Internationale des Femmes |
| **9 Mars** | 🎂 Anniversaire de Maman |
| **10 Mai** | 💐 Fête des Mères |

> *"Ce site ne ressemble à aucun autre cadeau, parce que toi, tu ne ressembles à personne d'autre."*

## 🚀 Comment utiliser le site

### Étape 1 — Extraire le dossier

```bash
# Décompresser l'archive
unzip site-maman.zip

# Entrer dans le dossier
cd site-maman
```

### Étape 2 — Ajouter les photos de Maman 📸

Copie les photos dans le dossier `images/` et renomme-les exactement comme ci-dessous :

```
images/
  ├── maman1.jpg      → apparaît sur index.html
  ├── maman2.jpg      → apparaît sur femme.html (8 mars)
  ├── maman3.jpg      → apparaît sur anniversaire.html
  ├── maman4.jpg      → apparaît sur maman.html
  ├── maman5.jpg      → apparaît sur souvenirs.html
  ├── maman6.jpg      → apparaît sur gratitude.html
  ├── maman7.jpg      → apparaît sur sagesse.html
  ├── maman8.jpg      → apparaît sur amour.html
  ├── maman9.jpg      → apparaît sur priere.html
  ├── maman10.jpg     → carrousel longévité (1ère image)
  ├── maman101.jpg    → carrousel longévité (2ème image)
  └── maman110.jpg    → carrousel longévité (3ème image)
```

> 💡 **Conseil :** Les photos verticales (portrait) sont les plus belles dans ce design.
> Formats acceptés : `.jpg`, `.jpeg`, `.png`, `.webp`

### Étape 3 — Ouvrir dans le navigateur 🌐

```bash
# Double-clic sur le fichier, ou via terminal :
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux
```

## 📖 Contenu de chaque page

### 🏠 Accueil
> *"Il existe des êtres qui portent en eux la douceur d'un matin de printemps…"*

La porte d'entrée du site. Présente les trois dates célébrées avec leurs badges dorés.
Un poème d'ouverture accueille Maman dans cet espace qui lui est entièrement dédié.

---

### 🌍 8 Mars — Femme
> *"Tu es la femme qui porte le matin sans jamais se plaindre du poids de la nuit."*

Un hommage à la **femme extraordinaire** qu'elle est, bien au-delà d'une journée symbolique.
Trois cartes célèbrent **sa force**, **sa grâce** et **sa lumière**.

---

### 🎂 Anniversaire — 9 Mars
> *"Ce jour-là, quelque part dans le monde, une étoile a brillé plus fort que les autres."*

Une page lumineuse avec des bougies animées ✦. Poème de naissance, vœux sincères,
et trois cartes : **Mon Vœu**, **Ma Prière**, **Ma Chanson**.

---

### 💐 Maman — Fête des Mères
> *"Tu as été médecin quand j'étais malade, professeure quand j'apprenais…"*

Une célébration de ce mot universel et intime : **Maman**. Ce qu'il contient vraiment.
Cartes : **Mon Foyer**, **Ma Gardienne**, **Ma Racine**.

---

### 📸 Souvenirs
> *"Il y a des odeurs qui me ramènent immédiatement à toi…"*

Les petits trésors de mémoire que rien ne peut voler.
Cartes : **Tes Plats**, **Tes Câlins**, **Tes Histoires**.

---

### 🙏 Gratitude
> *"Merci pour les nuits que tu as sacrifiées. Merci pour les rêves que tu as mis en pause."*

Une page entière pour dire **merci** — un mot qui ne suffit jamais.
Cartes : **Ton Temps**, **Ton Amour**, **Tes Leçons**.

---

### 🌿 Sagesse
> *"Tu m'as appris que la bonté n'est pas une faiblesse, que le silence peut être plus fort que les cris."*

Les enseignements précieux transmis, parfois sans le savoir.
Cartes : **La Patience**, **La Résilience**, **Le Partage**.

---

### ❤️ Amour
> *"Il n'existe pas de mot assez grand pour ce que je ressens pour toi."*

La page la plus intime. Un amour sans fond, sans condition, sans fin.
Cartes : **Sans Fin**, **Profond**, **Lumineux**.

---

### 🤲 Prière Islamique
> *رَّبِّ ارْحَمْهُمَا كَمَا رَبَّيَانِي صَغِيرًا*
> *"Seigneur, prends-les en pitié comme ils m'ont élevé tout petit." — Al-Isra, v.24*

Quatre **du'ât** (supplications) en arabe avec translitération et traduction française :
1. Pardon et miséricorde — *Allāhumma ghfir lī wa liwālidayya…*
2. Santé et bénédiction — *Allāhumma ishfihā wa 'āfihā…*
3. Honneur et pureté — *Allāhumma akrim mathwāhā…*
4. Paradis et protection — *Allāhumma adkhil-hal jannata…*

> **"Le paradis se trouve sous les pieds des mères."** — Hadith

---

### 🌺 Longévité & Santé
> *"Alors vis longtemps, Maman. Vis pour voir nos enfants grandir…"*

Une page-cadeau pour souhaiter une vie longue et belle, avec :
- 🎠 **Carrousel automatique** de 3 photos (← → ou swipe)
- 🌟 **5 icônes de vitalité** : Santé · Sérénité · Bonheur · Paix · Lumière
- 📜 **10 vœux** pour sa longévité (animés au scroll)
- ⏳ **Timeline de l'amour** : avant la naissance → aujourd'hui → demain

---

### ✦ Message Final
> *"Ce site est une lettre — une lettre que j'aurais dû t'écrire mille fois…"*

La lettre finale, complète et émouvante. Elle récapitule les trois dates, exprime l'amour
le plus profond, et se termine par une signature manuscrite.
Contient aussi les **liens rapides** vers toutes les pages.

## 🛠️ Personnalisation

### Changer les textes
Ouvre le fichier `.html` de la page souhaitée dans un éditeur de texte (ex: Notepad, VS Code).
Les textes sont dans les balises :
- `<div class="poem-block">` → poèmes
- `<div class="prose-block">` → paragraphes
- `<div class="gold-quote">` → citations dorées
- `<div class="card-text">` → textes des cartes

### Ajouter des photos au carrousel
Dans `longevite.html`, trouve le bloc `carousel-track` et ajoute une ligne :
```html
<img src="images/ta-nouvelle-photo.jpg" alt="Maman">
```
Mets aussi à jour le compteur `1 / 3` → `1 / 4` dans `carouselCounter`.

### Changer la vitesse du carrousel
Dans `longevite.html`, trouve :
```javascript
const INTERVAL = 3500; // ms entre chaque slide
```
Change `3500` (3,5 sec) par la valeur souhaitée.

### Changer les couleurs
Dans `style.css`, modifie les variables CSS en haut du fichier :
```css
:root {
  --rose:        #f9c6d3;   /* Rose principal */
  --gold:        #c9a84c;   /* Doré */
  --violet:      #c3aee0;   /* Violet */
}
```
